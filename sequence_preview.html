📊 Sequence Diagrams — ระบบ COMMU

แสดงการโต้ตอบระหว่าง Actor / Frontend / Backend / Database

Flow 1 — User Login

ข้อมูลที่วิ่งในระบบ:
📤 ส่งไป: username, password
📥 รับกลับ: access_token, refresh_token, role, user{id, full_name, phone, ...}
👤 Actor (User) ── Lifeline → Message (Data:Function) ⇠- Return Message alt ถ้า-อื่น ⊕ Self call
sequenceDiagram actor User as 👤 User participant FE as Frontend participant API as Backend API participant DB as Database User->>FE: กรอก username + password FE->>API: POST /api/accounts/login/ Note right of API: {username, password} API->>DB: SELECT user WHERE username=? DB-->>API: user record alt credentials ถูกต้อง API->>API: ตรวจสอบ password hash API->>API: สร้าง JWT token (role, full_name) API-->>FE: 200 OK — {access, refresh, role, user{...}} FE->>FE: บันทึก token ใน localStorage FE-->>User: เปลี่ยนหน้าไป Dashboard else credentials ผิด API-->>FE: 401 Unauthorized FE-->>User: แสดง error "ข้อมูลไม่ถูกต้อง" end

Flow 2 — Register Request + Admin Approve/Reject

ข้อมูลที่วิ่งในระบบ:
📤 ส่งไป: username, full_name, phone, address, citizen_id, house_owner_name, password, prefix?, birth_date?
✅ Validate: username ซ้ำ? | อายุ 18 ปีขึ้นไป?
📥 Approve: สร้าง User จริงใน DB | Reject: เปลี่ยน status เป็น "rejected"
👤 Actor (User) 🛡️ Actor (Admin) alt ถ้า-อื่น → Message ⇠- Return Message ⊕ Self call
sequenceDiagram actor User as 👤 User actor Admin as 🛡️ Admin participant FE as Frontend participant API as Backend API participant DB as Database User->>FE: กรอกฟอร์มสมัคร Note right of FE: username, full_name, phone,\naddress, citizen_id, password ... FE->>API: POST /api/accounts/register-request/ API->>DB: ตรวจ username ซ้ำ? DB-->>API: result alt username ซ้ำ API-->>FE: 400 — ชื่อผู้ใช้งานนี้ถูกใช้แล้ว FE-->>User: แสดง error else อายุ น้อยกว่า 18 ปี API-->>FE: 400 — ผู้สมัครต้องมีอายุ 18 ปีขึ้นไป FE-->>User: แสดง error else ข้อมูลถูกต้อง API->>API: hash password API->>DB: INSERT RegistrationRequest (status=pending) DB-->>API: saved API-->>FE: 201 — ส่งคำขอสมัครสำเร็จ รอผู้ใหญ่บ้านอนุมัติ FE-->>User: แสดงข้อความรอการอนุมัติ end Admin->>FE: เข้าหน้า /admin/users/approve FE->>API: GET /api/accounts/admin/requests/ API->>DB: SELECT RegistrationRequest WHERE status=pending DB-->>API: list of requests API-->>FE: รายการคำขอ FE-->>Admin: แสดงรายการรอการอนุมัติ alt Admin อนุมัติ Admin->>FE: กดปุ่ม อนุมัติ FE->>API: POST /admin/requests/{id}/approve/ API->>DB: BEGIN TRANSACTION API->>DB: INSERT User (role=user, verified=true) API->>DB: UPDATE RegistrationRequest status=approved DB-->>API: COMMIT success API-->>FE: 200 — อนุมัติสำเร็จ และสร้างบัญชีผู้ใช้แล้ว FE-->>Admin: แสดงผลสำเร็จ else Admin ปฏิเสธ Admin->>FE: กดปุ่ม ปฏิเสธ FE->>API: POST /admin/requests/{id}/reject/ API->>DB: UPDATE RegistrationRequest status=rejected DB-->>API: success API-->>FE: 200 — ปฏิเสธสำเร็จ FE-->>Admin: แสดงผลสำเร็จ end
